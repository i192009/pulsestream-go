# Security reporting

This repository is a synthetic-data development platform with public sample credentials. Do not put real credentials, customer payloads or personal financial data into issue reports. Report reproducible vulnerabilities privately to the repository maintainer through GitHub private vulnerability reporting when enabled. No private contact address is invented here.

See [deployment security boundaries](docs/security.md) and [known limitations](docs/limitations.md). The included dependency scans are an engineering check, not certification or a promise of a production security posture.
